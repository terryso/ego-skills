# Contributing

The contributor guide lives in [docs/CONTRIBUTING.md](./docs/CONTRIBUTING.md).

This repository accepts runnable [ego lite](https://lite.ego.app/) / `ego-browser` skills under the MIT license. Skills that do not use `ego-browser` belong in [claw-skills](https://github.com/terryso/claw-skills) or a repository of your own (`npx skills add`).
