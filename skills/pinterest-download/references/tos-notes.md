# ToS / ethics notes

- Personal / research use only; respect [Pinterest Terms](https://policy.pinterest.com/terms-of-service) and robots rules.
- Do not redistribute scraped media, sell datasets, or automate account creation / captcha bypass.
- Prefer content already visible in the user's logged-in Ego Lite session.
- Cap `limit`; avoid hammering `/resource/*` endpoints (script uses a single search page by default).
- Never commit exported session cookies or Ego profile files to git issues/PRs.
